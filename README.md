# Research Project

Welcome to the central repository for our research project.

## Project Structure

- `data/`: Datasets used for the project. Raw data is untouched, while processed data is cleaned and ready for analysis. (Note: Large datasets are ignored by Git).
- `docs/`: Literature review notes, meeting minutes, and weekly progress updates.
- `experiments/`: Outputs from various experiments, including interactions with Large Language Models (`llm_interactions/`).
- `paper/`: Drafts, figures, and materials for the final research paper.
- `resources/`: External reference materials like PDFs and useful links.
- `scratch/`: Personal scratchpads for individual testing and drafts.
- `src/`: Source code, scripts, and Jupyter notebooks for data processing and analysis.
